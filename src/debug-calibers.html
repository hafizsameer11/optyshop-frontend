Debug Calibers Issue

Open the browser console on the product page to see debug messages.

Navigate to: http://localhost:5173/shop/product/new

Expected Debug Messages:

  • [ProductDetail] Loading calibers for product: 116 new
  • [ProductDetail] Product mm_calibers: [array with 2 items]
  • [ProductDetail] Product calibers loaded from product data: 2 [array]
  • [ProductDetail] Auto-selected first caliber: {mm: "78", ...}
  • [ProductDetail] shouldShowCalibers calculation: {result: true, ...}

If calibers are not showing, check for:

  • "No calibers loaded" message - means productCalibers is empty
  • "No product" message - means product data is not loaded
  • result: false in shouldShowCalibers calculation
